# 🎬 Netflix Titles Data Analysis (Python Project)

## 📌 Project Overview

This project explores the Netflix Titles dataset using Python to analyze content distribution, trends, and patterns. The goal is to understand Netflix’s content strategy in terms of movies vs TV shows, country distribution, genres, and yearly content growth.

---

## 🎯 Objectives

* Analyze distribution of Movies vs TV Shows
* Identify top content-producing countries
* Explore trends in content release years
* Determine the most popular genres
* Analyze how Netflix content has evolved over time
* Understand patterns in content addition across years

---

## 📂 Dataset

* Source: Kaggle Netflix Titles Dataset
* File used: `netflix_titles.csv`
* Link: https://www.kaggle.com/datasets/shivamb/netflix-shows

---

## 🛠 Tools & Libraries Used

* Python
* Pandas
* NumPy
* Seaborn
* Matplotlib
* Google Colab

---

## 🧹 Data Cleaning & Preparation

* Converted `date_added` to datetime format
* Handled missing values in key columns (country, cast, director, rating)
* Dropped incomplete rows where necessary
* Standardized text columns
* Split multi-value columns (genres and countries)
* Extracted new features:

  * Year added
  * Month added
  * Main genre

---

## 📊 Exploratory Data Analysis (EDA)

The following analyses were performed:

* Distribution of content type (Movies vs TV Shows)
* Top 10 content-producing countries
* Release year distribution
* Top 10 genres
* Content addition trends over time

---

## 📈 Key Visualizations

* Countplot for content type distribution
* Bar charts for top countries and genres
* Histogram for release years
* Heatmap showing content type trends over time

---

## 🔍 Key Insights

* Netflix has significantly more movies than TV shows
* A small number of countries dominate content production
* Most content is relatively recent, showing focus on modern releases
* Certain genres like drama and comedy dominate the platform
* Netflix has increased content additions significantly over time

---

## 📌 Conclusion

The analysis shows that Netflix follows a data-driven content strategy focused on movies, recent releases, and a small number of high-producing countries. The platform continues to expand its content library rapidly to meet global demand.
